What are we comparing?

What is Jev?

Jev is TypeSafe’s decision model. It accepts state and typed questions: Choice selects an option, Noul estimates whether a condition is true, and Score places input on an ordered rubric. Read the primitive definitions.

How is this different from a typical LLM?

Jev returns native typed decisions. The OpenAI baseline uses the Responses API with gpt-6-astra and Structured Outputs by default. Both can produce machine-readable results. This collection compares their integration and observed responses; it does not assume a quality, speed or cost winner.

Are the previews real model results?

No. Previews are hand-authored fixtures shared by both panels. Live runs require your own keys and show request duration, estimated USD cost and provider-reported token usage. One request is not a benchmark.

When should I use a generative LLM?

Use a generative model when you need writing, explanations, code or multi-step synthesis. Use ordinary code for exact arithmetic, stable experiment assignment and hard constraints. These demos explore the bounded judgments between those two.

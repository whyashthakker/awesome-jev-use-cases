01 / Customer experience

Support ticket: Choice, Noul & Score

Choice + Noul + Score

Ask three different questions about the same flight-refund ticket.

Choice

Pick one known department. Jev returns every option’s probability and a separate confidence.

Noul

Does this request a refund? One probability from 0 to 1. Near 0.5 means unsure, not medium intensity.

Score

Calm → concerned → very angry. A probability-weighted score can land between levels, from 0 to 2.

Options & setup

Checking local configuration…

Add keys to .env on your computer and restart npm start. Keys stay on the local server. Preview mode ignores edits and uses the selected fixture. Live mode sends edited input to both providers.

Why a typed decision fits

The application needs one queue key per ticket; a written answer adds no routing value.

Scope of this demo

The preview probabilities and confidence are illustrative, not API measurements. Noul 0.5 means uncertainty, not medium intensity. Score runs from 0 to 2 here and can fall between levels.

Sources & pattern

Options & setup

Checking local configuration…

Add keys to .env on your computer and restart npm start. Keys stay on the local server. Preview mode ignores edits and uses the selected fixture. Live mode sends edited input to both providers.

Why a typed decision fits

The next maneuver is a closed action set, while motion and collision checks belong in code.

Scope of this demo

Synthetic text-to-maneuver visualization. Not a driving stack; no perception, trajectory planning or real-vehicle validation.

Sources & pattern

  • Farama HighwayEnv intersection
  • OpenAI Structured Outputs

Sources explain the pattern; they do not establish Jev performance on these original fixtures.

# Contributing

Keep each demo small: one decision, two contrasting synthetic inputs, a clear visual and a source link.

1. Edit the use case's `scenario.json` (or the optional `scripts/create-catalog.py` authoring source if regenerating the full catalog).
2. Preserve exact Choice/Score/Noul semantics and keep arithmetic in code.
3. Run `npm run check` and `npm run test:browser`.
4. Never commit keys, real customer data, unverified timing claims or fictional benchmark results.

`index.html` and per-example README files are generated by `npm run build`. Edit `scripts/build.js` to change their templates. The Python authoring script is optional and is not required to install, run or build this JavaScript project. It overwrites all scenario files if explicitly run; do not run it after hand edits unless you have updated the source.

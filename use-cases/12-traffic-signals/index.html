Options & setup

Checking local configuration…

Add keys to .env on your computer and restart npm start. Keys stay on the local server. Cost per run uses reported tokens and published list prices (Jev, OpenAI), verified September 20, 2026. Estimates exclude taxes, credits and negotiated rates; the response details and JSON export include the calculation. Preview mode ignores edits and uses the selected fixture. Live mode sends edited input to both providers.

Why a typed decision fits

The controller needs a phase enum and code-enforced interlocks.

Scope of this demo

Educational phase visualization only. No road infrastructure connection, timing optimization, safety certification or real-time control claim.

Options & setup

Checking local configuration…

Add keys to .env on your computer and restart npm start. Keys stay on the local server. Preview mode ignores edits and uses the selected fixture. Live mode sends edited input to both providers.

Why a typed decision fits

A high-volume triage step needs a flag and a category before human review.

Scope of this demo

Synthetic examples demonstrate an integration pattern. Validate on representative labeled data before choosing a model or an operating threshold.
